# **App Name**: MoeMoe Enterprises - Moving & Cleaning

## Core Features:

- Service Showcase: Display comprehensive descriptions and attractive visuals for all services (moving, cleaning) offered by MoeMoe Enterprises.
- Online Quote Request: Enable customers to easily submit quote requests through an intuitive online form, gathering necessary details for accurate estimates. Form submission uses PHP for validation and emailing the quote request to MoeMoe.
- Interactive Testimonials Carousel: Feature genuine customer testimonials in an engaging carousel format, fostering trust and highlighting service quality.
- Dynamic Contact Form: An animated and user-friendly contact form, complete with PHP-driven validation and email sending capabilities, encouraging seamless communication.
- Animated Visual Elements: Subtle yet impactful animations are integrated throughout the website using AOS and custom JavaScript to elevate user engagement and satisfaction.

## Style Guidelines:

- Primary color: Deep Blue (#041F66) to convey professionalism and reliability. This evokes the feeling of trust.
- Background color: Light Gray (#F3F4F6), to provide a clean and modern backdrop that enhances readability.  This color is a lighter tint of blue.
- Accent color: Vibrant Cyan (#48BFE3) is employed as a highlight color for buttons and key interactive elements. This provides visual pop while remaining analogous to the primary hue, promoting balance.
- Headings font: 'Poppins', sans-serif. Body font: 'Inter', sans-serif.
- A fluid, responsive layout ensures optimal viewing and interaction across all devices, reinforcing MoeMoe Enterprises' modern and accessible online presence.
- AOS library-driven fade-ins and subtle transitions are applied across the website to enhance user experience and provide a smooth feel when navigating the site. The transitions should feel fluid and subtle.
- Consistent usage of modern, minimalist icons to visually communicate core service offerings and key value propositions.
